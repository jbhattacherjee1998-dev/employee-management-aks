# AKS DEPLOYMENT PROJECT - COMPLETE STUDY NOTES

## PROJECT NAME

Employee Management API Deployment on Azure Kubernetes Service (AKS)

## PROJECT OBJECTIVE

Deploy a .NET Web API application to Azure Kubernetes Service using Docker, Azure Container Registry (ACR), and Kubernetes manifests.

This project demonstrates:

1. .NET Development
2. Docker Containerization
3. Azure Cloud
4. Kubernetes Orchestration
5. AKS Deployment
6. Azure DevOps Readiness
7. CI/CD Concepts

## Program.cs

Purpose:
Application Startup File

Example:

var builder = WebApplication.CreateBuilder(args);

Meaning:
Creates application builder object.

---

builder.Services.AddControllers();

Meaning:
Registers Controllers.

---

var app = builder.Build();

Meaning:
Creates Application Instance.

---

app.MapControllers();

Meaning:
Maps API Endpoints.

---

app.Run();

Meaning:
Starts Application.

========================================================

## EmployeeController.cs

Purpose:
Creates REST API Endpoint

Example:

[ApiController]

Meaning:
Marks class as API Controller.

---

[Route("api/[controller]")]

Meaning:
Route becomes:

api/employee

---

[HttpGet]

Meaning:
Respond to GET Request.

---

return Ok(...)

Meaning:
Returns HTTP Status 200.

## Dockerfile

Purpose:
Containerize Application

FROM mcr.microsoft.com/dotnet/sdk:8.0

Meaning:
Use .NET SDK image.

---

WORKDIR /src

Meaning:
Set working directory.

---

COPY . .

Meaning:
Copy source code.

---

RUN dotnet restore

Meaning:
Download dependencies.

---

RUN dotnet publish -c Release -o /app/publish

Meaning:
Build application.

---

FROM mcr.microsoft.com/dotnet/aspnet:8.0

Meaning:
Runtime Image.

---

COPY --from=build /app/publish .

Meaning:
Copy published files.

---

ENTRYPOINT ["dotnet","employee-management-aks.dll"]

Meaning:
Application Startup Command.

SECTION 7 : ACR (AZURE CONTAINER REGISTRY)
==========================================

Create Registry:

az acr create 
--resource-group aks-dev-rg 
--name myacr123 
--sku Basic

Purpose:
Store Docker Images

---

Login:

az acr login --name myacr123

---

Tag Image:

docker tag employee-api:v1 myacr123.azurecr.io/employee-api:v1

Meaning:

Source Image
Destination Image

---

Push Image:

docker push myacr123.azurecr.io/employee-api:v1

Purpose:
Upload Image to ACR

SECTION 8 : AKS COMMANDS
========================

node-count 1

SECTION 13 : RESUME DESCRIPTION
===============================

Built and deployed a containerized .NET 8 Web API on Azure Kubernetes Service (AKS). Implemented Docker-based containerization, Azure Container Registry integration, Kubernetes Deployments and LoadBalancer Services. Demonstrated cloud-native application deployment, container orchestration, scaling, and lifecycle management using Azure and Kubernetes.
